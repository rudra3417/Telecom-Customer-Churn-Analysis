# Telecom Customer Churn Analysis

## 1. Objective
The objective of this project is to analyze customer churn in a telecom company using Python and Pandas. The analysis focuses on understanding why customers leave, identifying churn patterns, and finding how contract type and customer tenure affect churn.

## 2. Dataset
- Dataset: Telecom Customer Churn
- Total Records: 7,043 customers
- Original Columns: 38
- Selected Columns: 12

## 3. Tools & Libraries
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 4. Project Steps

1. **Data Exploration**
   - Checked dataset structure, shape, columns, and data types.
   - Used basic statistical methods to understand the data.

2. **Data Cleaning**
   - Selected relevant columns.
   - Renamed columns for easier use.
   - Handled missing values.
   - Checked duplicate records and data consistency.

3. **Data Transformation**
   - Created a churn flag.
   - Grouped customers based on their tenure.

4. **Data Analysis**
   - Calculated the overall churn rate.
   - Analyzed churn categories and reasons.
   - Compared churn percentages across contract types.
   - Analyzed churn based on customer tenure.

5. **Data Visualization**
   - Created pie, bar, and line charts using Matplotlib.
   - Visualized customer status distribution.
   - Compared churn across contract types and tenure groups.
   - Displayed the major reasons for customer churn.

## 5. Key Insights

- Around 26.54% of customers have left the company.
- Competitor-related issues are the biggest churn category, with 841 customers.
- Month-to-month contracts have the highest churn rate at 45.84%, while two-year contracts have the lowest at 2.55%.
- Customers with 1–12 months of tenure have the highest churn rate at 47.44%.
- Customers with 49–72 months of tenure have the lowest churn rate at 9.51%.
- Better competitor devices and better competitor offers are the two most reported individual reasons for leaving.

## 6. Recommendations

- The company should focus more on customers with month-to-month contracts.
- Better offers and services could help compete with other telecom providers.
- New customers should receive better support and engagement to improve retention.
- Improving customer service and network reliability may help reduce dissatisfaction.
